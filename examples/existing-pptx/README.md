# Existing PPTX fixture

`fixtures/template.pptx` is generated by `npm run fixture:existing-pptx`. It contains three editable slides with a synthetic cover, one exact text placeholder, and a native chart. It contains no user or research data. `request.json` changes only slide 2.

The fixture generator is the source of truth; regenerate the PPTX before changing this fixture. Preview and QA artifacts belong under `outputs/`, not in this fixture directory.
