# Research application matrix

Checked 2026-11-12. This matrix separates guidance that was read from product features actually implemented. Recommendations are not treated as binding conference rules. No third-party slide template, font file, image, or code was copied.

## Research and communication guidance

| [Duarte, Resonate](https://www.duarte.com/resources/books/resonate/) — design methodology | Contrast between current state and possible future state can support a narrative. | `two-column-contrast` is available as a neutral comparison layout. | `src/render.mjs`; no automatic tension arc or unsupported dramatic claim generation. Book content not reproduced. |
| [Garr Reynolds](https://www.garrreynolds.com/tips) — designer guidance | Simplicity and restraint. | Three themes; bounded text; clean layouts without bundled stock artwork. | `themes/*.json`, `src/validate.mjs`. This is design advice, not a quantitative rule. |
| [Storytelling with Data](https://www.storytellingwithdata.com/book/downloads) — data communication practice | Explain the takeaway and reduce chart clutter. | Chart labels require units and y-axis text; bar charts reject a nonzero axis minimum; takeaway is rendered separately. | `src/validate.mjs`, `src/render.mjs`, tests. Chart correctness still requires comparison to source rows and visual review. |
| Native line chart extension — M2 first tranche | Show ordered observations as a trend while preserving source values. | CSV import accepts an explicit line-chart mode; native editable PowerPoint line chart uses markers and a zero-based axis; negative finite values are allowed for line series. | `src/import-csv.mjs`, `src/render.mjs`, `src/validate.mjs`, `examples/from-csv/synthetic-series.csv`; test `line charts accept finite signed values`; 8-slide `synthetic-line-demo` rendered and manually reviewed page by page on 2026-11-12. Synthetic values are not research evidence. |
| Multi-series, scatter and ECDF figure support — M2 figure core | Compare aligned observations, preserve numeric x/y pairs, and show empirical distributions without interpolation that changes their meaning. | Bar/line import aligns named series by category; scatter uses PptxGenJS's separate shared X values and Y series; ECDF groups ties into right-continuous steps using cumulative count / raw n. | Official [PptxGenJS chart API](https://gitbrent.github.io/PptxGenJS/docs/api-charts/) and chart demo inform the native chart mapping. `src/statistics.mjs`, `src/import-csv.mjs`, `src/render.mjs`, `src/qa.mjs`, `src/validate.mjs`; tests cover aligned series, signed scatter, CDF bounds and exact raw-to-step transformation. Three 8-slide synthetic decks rendered and manually reviewed on 2026-11-12. No uncertainty bars are emitted without repeated real observations. |
| Stable run identity and source-change audit — M2 provenance tranche | Reproducible updates need stable run and observation identifiers, immutable input hashes, and explicit change review. | Local CSV audit requires `run_id`, `run_timestamp`, and `observation_id`; source and row hashes support added/changed/removed row reports against a saved baseline. | `src/run-audit.mjs`, `tests/run-audit.test.mjs`, `docs/SCHEMA.md`; tool is offline and separate from the synthetic-only slide importer. Hash integrity does not prove source authenticity or scientific validity; removed rows require human review. |
| Local source refresh and shared Talk/Reading editions — M2 completion tranche | A reproducible update should expose changed inputs and processing cost; audience variants should preserve shared evidence lineage. | `src/refresh-runs.mjs` imports local run summaries, diffs manifests, rebuilds only on changed inputs, and records source/build hashes, QA, first/subsequent pipeline times. `src/build-dual.mjs` branches Talk and Reading from one validated storyboard/ledger; Reading appends source records and deterministic figure data/methods. | `tests/refresh-runs.test.mjs`, `tests/deck-profiles.test.mjs`, `npm run check`; CI uploads both variants and reports. Timings exclude rendering and human review; repair time is optional operator-supplied input. Hashes do not establish authenticity. PDF/DOCX source extraction remains optional and deferred. |
| Audience-aware storyboards and rule-linked Slide Critic — M3 initial implementation | MIT/CMU assert-and-evidence methods, Y Combinator clarity advice, Harvard readability/accessibility checklist, IEEE conference presentation guidance, and Google figure descriptions suggest concrete review prompts. | `src/critic.mjs` emits stable rule IDs, severity, slide ID/element field, recommendation and source reference. It checks audience/goal/duration metadata, assertion/evidence framing, unverified sources, chart counts/descriptions, and long text. `figure_description` is included in chart speaker notes. Optional AI planning carries audience, goal and duration, requests strict JSON Schema, limits evidence IDs to the ledger, and reports numeric literals absent from the brief. | `tests/critic.test.mjs`, `tests/validate.test.mjs`, `src/critique.mjs`; automated advice is advisory, does not score research validity, infer semantic grounding, or replace conference-specific instructions and visual review. Numeric grounding is lexical only. No paid API is called in CI or this implementation run. |
| AI draft approval gate and confirmed design tokens — M3 initial implementation | Human edit/review checkpoints are necessary for generated research claims; style exploration should precede reuse of design choices. | `src/review-draft.mjs` creates a separate reviewer-attributed copy with note, reviewed rule IDs and content hash; `src/cli.mjs build` blocks unapproved or stale AI drafts. `src/theme-gallery.mjs` renders cover+chart previews in three original project themes; `src/select-design.mjs` records an explicit reviewer-confirmed theme and copies its JSON tokens to a Markdown/JSON profile. | `tests/critic.test.mjs`, manually reviewed six theme PNGs in `outputs/m3/theme-gallery/`. No new copyrighted template/assets used. The generated gallery remains awaiting selection; no user style choice is represented as confirmed. |
| Independent-run means and uncertainty — M2 repeated-run tranche | Report variability at the experimental run unit and preserve assumptions, units and source lineage. | One pre-aggregated value per unpaired run/condition; ≥10 independent runs per condition; two-sided 95% Student-t interval for the mean, explicitly assuming independent, approximately normal run-level values. Editable custom error bars are serialized using DrawingML `errBars` plus/minus data. | NIST [Confidence Limits for the Mean](https://www.itl.nist.gov/div898/handbook/eda/section3/eda352.htm) documents the (t_{1-α/2,n-1}s/√n) interval. `src/statistics.mjs`, `src/import-repeated.mjs`, `src/chart-error-bars.mjs`, `src/qa.mjs`; tests verify the df=9 critical value, run lineage and XML error values. Microsoft [Open XML error-bar schema](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.drawing.charts.errorbars?view=openxml-3.0.1) and [`plus` / `minus` values](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.drawing.charts.minus?view=openxml-3.0.1). PptxGenJS does not expose an error-bar option in its current chart types; a narrowly scoped post-build patch preserves native chart editability. The fixture is synthetic; real data stays unverified pending source review. Paired designs and run drift are not modeled. |

## Community observations and future experiments

Community posts/videos are anecdotal prompts for failure modes, not evidence of comparative performance. Stories about repair time, text overflow, and number changes motivate regression cases and a future blinded benchmark. The sources in `REFERENCES.md` are not treated as a statistically representative sample. `docs/PRODUCT_BENCHMARK.md` defines how to measure alternatives before reporting scores.

## Reproducibility and licensing

The current codebase is MIT licensed. Only PptxGenJS and fflate are runtime dependencies; their lockfile versions are recorded in `package-lock.json`. External content is summarized as short principles with a link and scope. No proprietary slide designs, visual assets, fonts, or substantial source passages are redistributed.
