Exact runtime versions used in the local POC are recorded in [`BACKEND_BAKEOFF.md`](BACKEND_BAKEOFF.md). Third-party dependency, font, template, icon and model licenses remain separate from a project's top-level license and must be inventoried before redistribution.

- This is an integration triage, not legal advice. Pin commits/images and run a dependency/license scan before redistribution. Preserve notices for themes, fonts, icons, templates, models and runtime transitive dependencies.
- Treat source files, imported decks, external pages, Markdown and diagram text as untrusted content. Restrict browser fetches and network access by default.
- Slidev's renderer and the tested PPTAgent HTML-to-PPTX conversion both ran locally without model calls. Slidev has the integrated AIAutoSlides adapter; PPTAgent remains a separately invoked Skill workflow. Presenton generation requires an available provider: this local Ollama attempt did not complete. Model downloads/storage and hardware are not costless, and AI output remains a draft.
